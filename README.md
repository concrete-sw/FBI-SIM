# FBI-SIM

An AI-run FBI / detective investigation simulation that runs in the browser.

**To play:** download this repository as a ZIP (green **Code** button →
**Download ZIP**), unzip it, and double-click `fbi-sim/index.html`. Paste your
own AI API key on the login screen and you are in.

The game lives in [`fbi-sim/`](fbi-sim/). See its README for where to get an
API key, how to play, and how to add an AI provider.
